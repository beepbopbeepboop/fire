formal/hostmods/argparse.mojo: CPython's argparse, for the formal backend

Eighteen files the arm64 sweep listed fail only because they `import
argparse`. CPython's argparse is a shape over the source language rather than
a runtime facility — parsing a command line is scanning strings — so it is
reachable in principle on a freestanding arm64 image that links libSystem and
nothing else, and this file is the reason `argparse` is no longer in
HOST_MODLED's reachable half.

The API is not `ArgumentParser()` because three measured properties of this
target make that shape impossible: a module dylib can return one 64-bit word
and nothing else (a struct or a list is a blob in the frame that made it), a
module has no state to accumulate into, and `argc`/`argv` are overwritten by
the entry stub before the first statement runs — so `parse_args()` reading
`sys.argv` has no SOURCE here at all. The shape that is left is the one the
value model allows and the one that is testable: the caller owns the state. A
parser is a string the caller writes, the command line is a list the caller
already has, the result is written into a caller's buffer, and every value is
text.

test_formal_argparse.py generates TWO programs from ONE table of `add_argument`
declarations and command lines — one that uses CPython's own argparse, one that
uses this module — builds the second as an arm64 image, RUNS it, and requires
identical stdout, stderr and exit status. 42 cases, covering values, defaults,
abbreviations, `--opt=value`, combined short flags, the `--` separator, every
nargs shape, choices, type errors, required errors, unrecognized arguments, the
usage line, the error wording, the help layout and exit status 2.

What it will not do, and says so at the top of the file: `type=float` is
REFUSED (a value here is one integer word; `2.5` is the integer 2, measured),
subparsers and mutually exclusive groups are absent (a subparser is a second
parser reachable from the first), and help text is laid out but not wrapped (a
terminal is a host object, so 78 columns is the only width this target can
know).
