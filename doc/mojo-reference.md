# Mojo Language Reference

This is the main index for Mojo's official language reference documentation.

## Core Reference Sections

The documentation is organized into seven primary reference areas:

1. **Identifiers & Keywords** - Covers naming conventions, reserved words, escaped identifiers, and argument conventions

2. **Literals** - Documents integer, floating-point, string, t-string, boolean, None, and Self literals

3. **Expressions** - Details tuples, collection displays, member access, calls, subscripts, ternary conditionals, and comprehensions

4. **Operators** - Explains operator precedence, associativity, and implementing operators for custom types

5. **Simple Statements** - Covers imports, assignments, return, raise, break, continue, and compile-time declarations

6. **Compound Statements** - Addresses if statements, loops, error handling with try/except, context managers, and compile-time control flow

7. **Function Declarations** - Describes signatures, parameters, arguments, default values, constraints, effects, and special methods

## Purpose

The reference is designed as a concise lookup resource for Mojo's syntax and grammar constructs, organized by language element for quick access to specific rules and forms.
