A/B + Interpreter Parity — 100% Python Compatibility

Goal: (1) byte-identical .ci between python3 mojo.py --dump X.mojo and MOJO_NO_SHIM=1 ./mojoc X.mojo --dump; (2) runtime output parity between python3 mojo.py run X.mojo (interpreter) and python3 mojo.py --jit X.mojo (compiled); (3) all existing quality gates stay green after every change.

Architecture reality

Both gimple_codegen.py and myinterpreter.py dispatch on AST nodes via getattr(self, f'handler_{type(node).__name__}')(node). As Python both work. But mojoc is gimple_codegen.py compiled to C — the getattr(self, name)(node) compiles to an indirect call stubbed to (int64_t)0, so every statement/expression body is dropped in the native output. This is the linchpin (Class B).

Track A — Native backend A/B parity (byte-identical .ci)

  1. A1. Static dispatch refactor (linchpin, Class B). Replace getattr(self, handler_name)(node) in gen_stmt/lower_expr with a compiled-friendly static dispatch: explicit isinstance chain (precedent: _cpp_stmt compiles cleanly). Keep handler bodies byte-identical; only change the dispatch seam. Verify Python-path output unchanged (diff the 7 A/B files before/after). Unblocks string pool / _intern_string / _slit_.
  2. A2. Container-truthiness for module-level sets (Class A). Extend the existing bool(container) length-check fix (_ensure_bool_cond/_lower_UnaryOp) to module-level globals boxed as int64_t, so empty-set tests are correct.
  3. A3. Comprehension no-op + char-truncation (Class C). Fix [self._param_ctype(pn, pt, s) for pn, pt in s.params] lowering (23733); fix (char) pointer-truncation in the func_return_types.get(fn.name,...) dict-key path (27513).
  4. A4. Deterministic _SELFHOST_DIR (Class D). Make __file__-derived _SELFHOST_DIR a compile-time constant in the binary, not process CWD.
  5. A5. Verify Class E. Top-level segfault should vanish once A1 lands; fix residual indirect-call paths if any.

Order: A1 first (unblocks everything), then A2–A4 independently, A5 as verification.

Track B — Interpreter parity + runtime harness (parallel)

  1. B1. Runtime-diff harness. New harness: run corpus via mojo.py run and mojo.py --jit, diff stdout+exit. Corpus: 7 A/B files → test_simple + builtins → stdlib tests. Wire into make check.
  2. B2. Close interp-vs-compiled gaps (per the table above: LambdaExpr, ImagLiteral, MatchStmt capture, DelStmt, async for/with, failure mode alignment).
  3. B3. Cross-path lockstep discipline. Apply each fix to BOTH paths with a cross-path test (pattern: bugs/CHAINED_COMPARISON_WRONG_RESULT.md). Add per-fix coverage to the runtime-diff harness.

Execution model

  • Two agents in parallel: Track A (native dispatch + divergence classes), Track B (interpreter parity + runtime harness).
  • Independent file surfaces: Track A → gimple_codegen.py, module_loader.py, runtime; Track B → myinterpreter.py, new harness.
  • After each landing: run the full shared gate; reconcile cross-track breakage.
  • Land changes as separate commits per divergence class / semantic gap.

Risks / mitigations

  • Static dispatch refactor is large → change only the dispatch seam, never handler bodies; verify Python-path output byte-unchanged.
  • Comprehension fix (A3) could ripple → isolate; rely on full gate.
  • Interp async-refusal could break tests → check test_generators.py/test_async_execution.py before changing async for/with.
