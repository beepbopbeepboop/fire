# FORMAL_eval_eq_mojo_bridge_red_on_head-part2: Compositional universal walk over the block sequence in `_gen_universal_e2e_cfg`

## Goal

Replace the DFS in `_gen_universal_e2e_cfg` that emits the whole walk per CFG-path leaf with **ONE inductive walk over the block sequence** — a single chain of `rec1_glue_gen` advances and `go_exit_cbz_taken`/`go_exit_cbz_fall` edges, closing `hcond`/`hprior` once per `(block, branch)` instead of once per leaf. `lib/Contracts.lean`'s `Refine.BlockCert` / `runs_to_body` already provides the machinery (`bigbody_prog`, the 29 `bigbody_blk_N` block theorems, the `…_runs`/`…_mid` certificates). The current output walks every leaf independently, inflating declarations exponentially with condition count.

## Acceptance

After the change, the emitted universal proof is a single inductive chain over all blocks:
- The terminal proposition is built by one chain of `rec1_glue_gen` advances and `go_exit_cbz_taken`/`go_exit_cbz_fall` edges across the block sequence.
- `hcond`/`hprior` pairs appear once per `(block, branch)`, closed by `hcond_close(list(def_names) + _cs_defs + _hpriors)`.
- Declaration count grows linearly with the number of blocks, not exponentially with the number of conditions.
- The generated file still carries the pieces it composes (`bigbody_prog`, `bigbody_blk_N`, `…_runs`/`…_mid` certificates).

Verified by text assertions on the generated bytes — no Lean run required.

## Status 2026-11-27: design guide (planning round, no generator change landed)

Measured by reading `emit_block` (`formal/arm64_proof_gen.py` ~10850-12290) and
generating a two-`if` fixture (`def two(n)`, 6 707 lines) and `bigbody`.

**What is already generic.** Every per-block `…_bN_runs` / `…_bN_mid` is
quantified over the entry state (`∀ st, st.pc = start → …`), and `rec1_glue_gen`,
`go_exit_cbz_taken/fall`, `go_exit_step` take the state as an argument. So the
control walk has no need to be re-derived per path. What is per path is the
emitter's recursion, which instantiates them at a path-specific state term.

**Shape that composes (control half).** For an acyclic, call-free walk, per block
`k` in reverse topological order emit
`def R_k (s) : State` (the block's `qS` run, then `if cond then R_taken … else R_fall …`;
`R` of a `RET` block is its run state), `def c_k (s) : Nat` (instructions consumed on
that path), and one theorem
`T_k : ∀ s f, s.pc = start_k → need_k ≤ f → arm64_go_exit s C EXIT f = arm64_go_exit (R_k s) C EXIT (f - c_k s)`
plus `c_k s ≤ need_k` (one `split <;> omega`). `T_k` is `rec1_glue_gen` +
`go_exit_cbz_*` + the IH `T_taken`/`T_fall`; a join block's `T_join` is used by both
arms, so the declaration count is linear in blocks. Fuel is `∀ f ≥ need_k`, not an
exact literal, because path costs differ at a join.

**Why that alone does not close the bug (the wall).** The walk also carries VALUE
facts the generic-state form cannot see:
1. the `RET`'s `x30 = EXIT` (`hx30_k`) comes from the prologue's stack slot
   surviving every block on the path;
2. the stack-floor guard's dead trap arm (`_dead_edges`, `hguard_k`) is closed from
   the concrete `Arm64State.init` memory;
3. `hcond_k`/`hprior_k` tie each branch to the SOURCE condition on `n` and need the
   path's `s_k` chain unfolded.
These need a join invariant `Inv_k s` (slot holds EXIT, `s.sp`, locals' registers
relate to `n`), stated per block, preserved by each block's `qS` chain, and used as
premises of `T_k`. That is the "contract-shaped" proof in the part1 doc's step 2,
and it is the real work: designing `Inv_k` per block from `_frame_read_addrs` /
`_var_regs`, then re-deriving `_emit_terminal_flow` over `R_0 init` instead of over
a path's `hsid` chain (64 leaves of terminal value flow remain for `bigbody`, now
without the 894 advances).

**Ordering constraint measured in earlier rounds.** `bigbody` dies at
`bigbody_b40_self1` in the block-theorem PREFIX, before the universal theorem is
read (third-round table). A compositional universal theorem cannot turn the named
command green until the prefix is under the ceiling (part1 / parent doc's item 1,
hoisting the `qS_k` chain facts). Do that first, then this.

**Plan, files and tests.**
1. Hoist per-block `qS_k` simplifications (`_gen_block_run`-side, parent doc item 1),
   Lean-free pin + `bigbody` prefix measured under 6 GB.
2. New `_gen_universal_walk_compositional` beside `_gen_universal_e2e_cfg` (not
   inlined into its 3 200 lines), selected only for acyclic, call-free, non-contract
   walks; `_gen_universal_e2e_cfg` keeps the DFS as fallback.
3. Prototype in Lean by hand on `two` first (check with `lean`, ~minutes), then
   `ifonly`/`condassign`/`elif3`, then `bigbody`.
4. Add `TestBridgeSimpset.test_the_universal_proof_walks_blocks_once_not_per_leaf`
   only together with the emitter, asserting per-block `T_k` count == block count
   and that no `hsid_` chain is duplicated; the Lean half (`TestBridgeTypechecks`)
   is what proves soundness, the text test alone would not.

`_gen_universal_e2e_cfg` before the theorem header; off by default,
`_WP_MIN_PATHS = 10**9`; enable with `_WP_MIN_PATHS = 5`). Per reachable block `k`:
`def …_wp_k n s : Prop` (weakest precondition = the control structure), and
`theorem …_T_k : ∀ s f, s.pc = start_k → need_k ≤ f → wp_k n s → match go_exit …`.
A conditional whose two arms are straight (`seq`/`b`) chains to a common join is a
DIAMOND: `wp_k n s := wp_join n (M_k (run_exit s))` with `def M_k t := if cond then

arms `False`, the trap `BL` arm `True` (`none` arm), halt blocks use their halts
certificate. Declined (falls back to the per-path walk): loops, calls, contracts,

### Update 2026-11-27 (very last): the kernel wall is proof-term DEPTH, not just size

`ifs4` re-run with the generated-proof ceiling lifted (`-M 24000`, 30 GB memcap):
it does not pass either, it fails with `(kernel) deep recursion detected` after
121 s and 10.3 GB. So raising the memory budget is NOT a way out: the one-theorem
chain of per-layer `simp` rewrites nests too deeply for the kernel. The split has
to be real, one top-level declaration per layer, which means each layer's
statement must be writable by the generator WITHOUT running `simp`. That needs
a per-block invariant stated in closed form (what each merged state's register
and stack-slot values are, as functions of `n`), e.g. emitted from the same
per-block effect the run certificates already carry (`…_qS/qT` over a symbolic
entry whose fields are named hypotheses), and then `V_k : Inv_k s -> Inv_next
(M_k (e s))` proved once per block by `simp`. This is the "contract-shaped"
design from the first guide; the measurements above are why it is required
rather than optional. Do not retry bigger budgets, `maxSteps`, or one-theorem
normalization.

### Experiment 2026-11-27: hoisting each layer into an aux theorem (`layer` tactic)

Instead of stating each layer by hand, a small meta tactic hoists the proof step a
tactic block produced into its own `mkAuxTheorem` (so the kernel checks one
shallow theorem per layer and the main term is a chain of applications). It
compiles on `lean` 4.32.2 and works on a toy goal (`example … := by layer (simp
only [Nat.add_zero]); exact ⟨h, trivial⟩`):

```lean
open Lean Elab Tactic Meta in
elab "layer " t:tacticSeq : tactic => do
  let g ← getMainGoal
  g.withContext do
    let gty ← g.getType
    let g' ← mkFreshExprSyntheticOpaqueMVar gty (← g.getTag)
    let rest ← getGoals
    setGoals [g'.mvarId!]
    evalTactic t
    let gs ← getGoals
    let v ← instantiateMVars g'
    let gsE := gs.map mkMVar
    let lctx ← getLCtx
    let used ← do
      let mut st : CollectFVars.State := {}
      st := collectFVars st (← instantiateMVars gty)
      st := collectFVars st v
      for e in gsE do st := collectFVars st (← instantiateMVars (← inferType e))
      pure st.fvarSet
    let mut fvs : Array Expr := #[]
    for d in lctx do
      if !d.isImplementationDetail && used.contains d.fvarId then fvs := fvs.push d.toExpr
    let allArgs := fvs ++ gsE
    let aux ← mkAuxTheorem (← mkForallFVars allArgs gty) (← mkLambdaFVars allArgs v)
    g.assign (mkAppN aux allArgs)
    setGoals (gs ++ rest)
```

Applied to every layer of the 4-`if` proof (`| (layer (simp only [wp_k]; try simp …))`)
it does NOT fix it: the failures move INSIDE single layers (`(kernel) excessive
memory consumption` on the aux theorem of a layer, plus one `maxRecDepth`). So the
per-layer `simp` proofs are themselves too heavy for the kernel once the state
carries the full write-chain memory and the 44-field record, which means the
invariant approach (state only what each layer changes, as closed forms over `n`)
is required, not just a split. Evidence the heavy part is the memory term: the
guard/flag reasoning is closed arithmetic and cheap; every layer re-proves
`mem_read_u64 (mem_write_u64 …)` address side conditions with `disch := decide`
over the whole chain. Next experiment: give `simp` a SMALL memory by abstracting
the stack frame as named slots (`mem_write_u64`'s base as a variable `m0` with the
read-after-write facts for the frame slots proved once), so layers rewrite over
`m0` plus a handful of writes instead of a growing lambda chain.

### Experiment 2026-11-27 (b): straight-line `layer` script, `-M 24000` — a SINGLE layer already fails

decide)` proves one address inequality per link per read; `two`/3 `if`s fit,
4 do not.

Next, in order (each a 2-minute Lean run on `ifs4` with only layer 0 kept and the
