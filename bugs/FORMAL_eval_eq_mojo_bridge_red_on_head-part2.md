# FORMAL_eval_eq_mojo_bridge_red_on_head-part2: Compositional universal walk over the block sequence in `_gen_universal_e2e_cfg`

## Goal

Replace the DFS in `_gen_universal_e2e_cfg` that emits the whole walk per CFG-path leaf with **ONE inductive walk over the block sequence** — a single chain of `rec1_glue_gen` advances and `go_exit_cbz_taken`/`go_exit_cbz_fall` edges, closing `hcond`/`hprior` once per `(block, branch)` instead of once per leaf. `lib/Contracts.lean`'s `Refine.BlockCert` / `runs_to_body` already provides the machinery (`bigbody_prog`, the 29 `bigbody_blk_N` block theorems, the `…_runs`/`…_mid` certificates). The current output walks every leaf independently, inflating declarations exponentially with condition count.

## Acceptance

After the change, the emitted universal proof is a single inductive chain over all blocks:
- The terminal proposition is built by one chain of `rec1_glue_gen` advances and `go_exit_cbz_taken`/`go_exit_cbz_fall` edges across the block sequence.
- `hcond`/`hprior` pairs appear once per `(block, branch)`, closed by `hcond_close(list(def_names) + _cs_defs + _hpriors)`.
- Declaration count grows linearly with the number of blocks, not exponentially with the number of conditions.
- The generated file still carries the pieces it composes (`bigbody_prog`, `bigbody_blk_N`, `…_runs`/`…_mid` certificates).

Verified by text assertions on the generated bytes — no Lean run required.
